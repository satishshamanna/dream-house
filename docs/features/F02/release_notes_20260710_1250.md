# Release Notes: F02 - Smart Property Open House Scheduler (US01 Schema Only)

**Release Date**: July 10, 2026  
**Release Package Version**: v1.0.0-schema  
**Status**: 🟢 **READY FOR DEPLOYMENT**  

---

## 1. Feature Description
This release deploys the database schema foundation for the **Smart Property Open House Scheduler** feature. It includes the custom property size field and the new `Open_House__c` custom object and fields, along with user-level FLS read/write access mappings.

---

## 2. Included Metadata Components

| Metadata Type | Member Name | Description |
| :--- | :--- | :--- |
| **CustomField** | `Property__c.Size_SqFt__c` | Represents the interior size of the property in square feet. |
| **CustomObject** | `Open_House__c` | SObject representing scheduled open house events. |
| **CustomField** | `Open_House__c.Property__c` | Lookup field linking the open house to a Property. |
| **CustomField** | `Open_House__c.Open_House_Date__c` | DateTime field for the scheduled viewing. |
| **CustomField** | `Open_House__c.Max_Capacity__c` | Number field representing maximum calculated visitor capacity. |
| **CustomField** | `Open_House__c.Registered_Visitors__c` | Number field tracking visitor registrations (default 0). |
| **PermissionSet** | `dreamhouse` | Updated permission set to grant CRUD access to Open Houses and FLS to all fields. |

---

## 3. Testing and Verification

### Automated Test Runs
- No Apex code or LWC components are included in this schema-only release. No unit tests are required.

### Manual Verification Path
Refer to the manual test scripts under the story folder:
1. Navigate to **Setup** > **Object Manager** > **Property__c** > **Fields & Relationships** to verify `Size_SqFt__c` exists.
2. Navigate to **Setup** > **Object Manager** > **Open_House__c** to verify the custom object exists with `Property__c`, `Open_House_Date__c`, `Max_Capacity__c`, and `Registered_Visitors__c`.
3. Check the `dreamhouse` permission set to confirm FLS permissions.

---

## 4. Manual Deployment & Post-Deployment Steps

For successful activation of the database schema, the deployment team must verify:

### Step 1: Assign Permission Set to Brokers
1. Navigate to **Setup** > **Users** > **Permission Sets**.
2. Select the **dreamhouse** permission set.
3. Click **Manage Assignments** > **Add Assignments**.
4. Select all active Broker users and click **Assign**.
