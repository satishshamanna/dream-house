# Release Notes: F02 - Smart Property Open House Scheduler (US02 Controller Only)

**Release Date**: July 10, 2026  
**Release Package Version**: v1.0.0-controller  
**Status**: 🟢 **READY FOR DEPLOYMENT**  

---

## 1. Feature Description
This release deploys the backend Apex logic for the **Smart Property Open House Scheduler** feature. It includes the controller methods for schedule querying, date scheduling (with dynamic size-based capacity calculation), and visitor registration limits, as well as the unit tests and permission mappings.

---

## 2. Included Metadata Components

| Metadata Type | Member Name | Description |
| :--- | :--- | :--- |
| **ApexClass** | `OpenHouseController` | Backend logic to securely query, schedule, and register open house visitors. |
| **ApexClass** | `OpenHouseControllerTest` | Unit tests to verify controller queries, capacity logic, defaults, and registration limits. |
| **PermissionSet** | `dreamhouse` | Updated permission set to grant enabled access to `OpenHouseController`. |

---

## 4. Manual Deployment & Post-Deployment Steps

For successful activation of the Apex controller, the deployment team must verify:

### Step 1: Assign Permission Set to Brokers
1. Navigate to **Setup** > **Users** > **Permission Sets**.
2. Select the **dreamhouse** permission set.
3. Click **Manage Assignments** > **Add Assignments**.
4. Select all active Broker users and click **Assign**. (Skip if already assigned in US01).

### Step 2: Validate Apex Tests
1. Run validation of the deployed Apex class in the target Org to ensure zero regressions:
```bash
sf apex run test --classnames OpenHouseControllerTest --result-format human
```
