# Release Notes: F01 - VIP Buyer Matcher

**Release Date**: July 10, 2026  
**Release Package Version**: v1.0.0  
**Status**: 🟢 **READY FOR PRODUCTION**  

---

## 1. Feature Description
The **VIP Buyer Matcher** provides real estate brokers with an instant sidebar view of matching VIP buyers (Contacts) directly on the Property detail page layout. Match selection is calculated automatically based on Property price (matching Contacts' maximum budget) and bedroom configurations.

---

## 2. Included Metadata Components

| Metadata Type | Member Name | Description |
| :--- | :--- | :--- |
| **CustomField** | `Contact.Budget__c` | Represents the maximum budget of the contact. |
| **CustomField** | `Contact.Beds__c` | Represents the minimum preferred beds of the contact. |
| **ApexClass** | `VIPBuyerController` | Backend logic to securely query matching contacts with sharing checks. |
| **ApexClass** | `VIPBuyerControllerTest` | Unit tests to verify query logic, boundaries, and limits. |
| **LightningComponentBundle** | `vipBuyerMatcher` | Reactive widget to display matches on record page sidebar layouts. |
| **PermissionSet** | `dreamhouse` | Enabled Contact field-level security and class accesses. |

## 4. Manual Deployment & Post-Deployment Steps

For successful feature activation, the deployment team must manually perform the following post-deployment configuration steps in the target Org:

### Step 1: Assign Permission Set to Brokers
1. Navigate to **Setup** > **Users** > **Permission Sets**.
2. Select the **dreamhouse** permission set.
3. Click **Manage Assignments** > **Add Assignments**.
4. Select all active Broker users and click **Assign**.

### Step 2: Add LWC Component to Property Detail Page
1. Navigate to the **Dreamhouse** or **Sales** app.
2. Open any active **Property** record page.
3. Click the **Setup Gear** icon in the upper right and select **Edit Page** to open Lightning App Builder.
4. Locate the custom component **vipBuyerMatcher** in the component list on the left.
5. Drag and drop the component into the right-hand sidebar layout.
6. Click **Save** and then click **Activate** (if the page is not activated as Org Default, assign it as Org Default for Desktop).
7. Return to the record page to verify the sidebar widget displays.
